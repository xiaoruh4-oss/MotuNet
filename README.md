# Motu Net · Weak Network Lab

[下载最新安装包](https://github.com/xiaoruh4-oss/MotuNet/releases/latest) · [全部版本](https://github.com/xiaoruh4-oss/MotuNet/releases)

Motu Net 是面向 Windows 桌面端的网络条件模拟工具，用于游戏客户端和服务联调。首版通过自写 Python `ctypes` 适配器调用 WinDivert，在本机网络层对匹配的数据包施加延迟、抖动、丢包、限速等策略。

> **安全提示**：启动网络实验会影响本机流量。请只在测试环境和已获授权的设备上使用，实验结束后点击“停止并恢复”并确认状态恢复。程序启动时不会自动开启网络拦截；开始实验时系统可能弹出管理员提权对话框。

## 环境与安装

- Windows 10/11 x64；需要管理员权限才能打开 WinDivert 驱动。
- Python 3.11+（开发运行）或打包后的 `MotuNet.exe`（用户运行）。
- 仓库已包含 `vendor/windivert/WinDivert.dll`、`WinDivert64.sys` 及其许可证。

开发环境安装：

```powershell
cd NetLab
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

构建 Windows onedir 包：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\tools\build_release.ps1
```

安装包位于 `deliverables/MotuNet-0.5.2-Setup-x64.exe`

可直接把安装包发给同事。安装向导显示实际安装目录，可点击“浏览”修改；检测到原安装记录时默认沿用原目录，确认后覆盖升级。完整程序目录位于 `staging/MotuNet`。真实网络测试需先点击“以管理员身份重启”，再点击“开始测试”。

常规升级会跳过内容相同的网络驱动，避免重复替换导致重启电脑。若未来驱动本身发生变化且仍被占用，安装器会提示必要的重启。

## 使用方法

1. 在“场景”页选择预设（轻度弱网、地铁/电梯、高延迟、丢包专项、低带宽、短时断网、延迟断网、正常对照），或编辑自定义参数。
2. 设置匹配范围：IP、端口、协议（TCP/UDP）、方向（入站/出站/双向）、localhost，以及高级 WinDivert filter。高级 filter 仅允许经过语法校验的表达式，并自动排除 `impostor` 数据包。
3. 点击“开始测试”。状态栏显示运行时长、收发包、丢弃、重复、乱序、队列和错误计数。
4. 可设置定时停止（秒）；到时引擎自动停止。随时点击“停止并恢复”可立即清空队列并关闭句柄。
5. 运行中选择其他场景后，点击“切换并启动”会先恢复当前网络，再启动新场景。当前选中参数已生效时按钮显示“当前场景运行中”，不可重复启动；停止后可重新开始。顶部始终显示实际运行的场景和阶段。

## 在线更新

- 0.5.0 起，程序启动后会后台检查 GitHub 最新稳定版；左下角“检查更新”可随时手动检查。
- 发现新版本后显示更新说明。选择“下载并更新”会先停止当前测试并恢复网络，下载并校验安装包，再打开安装向导；“稍后”保持当前版本。
- 自动检查失败不会打断正常使用。正在测试时，自动发现新版会等测试结束再提示；下载可取消，失败后可重试。
- 公开安装包无需 GitHub 账号，但网络须能访问 GitHub 及其文件下载服务。
- 0.4.x 不具备更新检查功能，需手动安装一次 0.5.0 或更高版本。用户场景和皮肤保存在安装目录外，升级会保留。
- 发布与开发流程见 [GitHub 发布说明](docs/github-release.md)。

## 皮肤与场景库

- 左下角“皮肤”按钮可选择蓝白、深色、青绿，立即生效并记住选择。切换皮肤不会改变正在运行的测试。
- “新建场景”：输入名称，从正常网络参数开始创建，调整后点击“保存修改”。
- “另存为新场景”：复制当前全部参数（包含 IP、端口、方向和断网时间），输入新名称保存，保留原场景。
- 已保存的自定义场景会出现在左侧列表，重开软件仍可选择；“保存修改”只更新选中的自定义场景。内置场景改动需另存，内置模板会保留。
- “删除场景”：选中已保存的自定义场景，点击左侧删除按钮并确认。删除后回到“正常对照”，不会启动测试；取消会保留场景和当前修改。内置场景不可删除，测试或更新期间删除按钮暂不可用。
- “导入场景”载入 JSON 后可直接测试，也可保存到场景库；“导出场景”用于分享给同事。取消名称输入或名称重复均不会覆盖原场景。
- 场景保存在 `%LOCALAPPDATA%\MotuNet\scenarios`，皮肤偏好保存在同目录下的 `theme_settings.json`；升级不会清除这些用户数据。
- 基础区显示带宽、延迟、丢包；“高级选项”内有重复、乱序和短时断网，选择含这些条件的场景会自动展开。

## 首版支持范围

- 延迟与随机抖动（毫秒）
- 丢包率、短时 blackout（等效 100% 丢弃）
- 带宽限制（KiB/s，按方向排队）
- 数据包重复率、乱序延迟
- IP/端口/协议/方向/localhost/高级 filter 匹配
- 定时停止、运行统计、操作日志、本地 JSON 配置和预设场景

## 限制与已知问题

- 仅支持 Windows x64；依赖 WinDivert 驱动，非管理员环境无法完成真实端到端拦截。最终真实测试状态以测试记录为准，本 README 不宣称已完成。
- 不能按进程筛选，不能直接控制手机或其他设备；如需移动端测试，请在目标设备或网关上部署独立方案。
- TCP 重置（RST）列入后续路线，首版未实现，界面和文档不应将其视为已支持功能。
- 日志是本机操作记录，不是防篡改的企业审计系统。
- 复杂 filter、IPv6、驱动版本兼容性可能因系统策略而异；请先用“正常对照”场景验证链路。

## 测试建议

开发者可运行：

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -q
```

在具备管理员权限的 Windows 测试机上，建议按“正常对照 → 轻度弱网 → 丢包专项 → 低带宽 → 短时断网”的顺序执行，并记录客户端表现、服务端日志和 Motu Net 统计。每次实验后确认停止成功、网络恢复、无残留 WinDivert 句柄。

## 本机限定冒烟测试

tools/live_smoke.py 仅使用随机绑定的 127.0.0.1 UDP 端口和精确 WinDivert filter，不影响其他网络流量。请在管理员 PowerShell 中运行：

```powershell
.\tools\run-live-test.ps1 --output live_smoke_report.json
```

脚本不会自动提权；非管理员返回码为 2 并写出跳过报告。



## 延迟断网

勾选“完全断网”后设置“延后断网”和“断网持续”：开始测试后先保持网络正常 N 秒，再对匹配流量断网 M 秒，结束后自动恢复。将“延后断网”设为 0 即立即断网；仅在立即断网时允许将“断网持续”设为 0，表示手动停止。等待和断网阶段的剩余时间会显示在状态区，点击“停止并恢复”可提前结束。

勾选“循环执行”后，自动重复“正常联网 N 秒 → 断网 M 秒 → 恢复网络”，直到点击“停止并恢复”。循环模式下两段时间均需至少 1 秒；例如延后 10 秒、持续 5 秒，会每轮联网 10 秒、断网 5 秒。顶部显示当前轮次和阶段倒计时。循环开关默认关闭，可随自定义场景保存、导入和导出。循环模式不使用普通测试的“自动恢复”时长，停止、切换场景或关闭窗口会结束循环并恢复网络。
