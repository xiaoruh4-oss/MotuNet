# 需求说明

## 背景

游戏 QA 需要在 Windows 桌面机上稳定复现延迟、抖动、丢包、限速和短时断网等网络条件。现有 clumsy 工具可作为功能参考，但公司需要中文界面、预设、配置和日志，并保持实现可控。

## 用户与目标

目标用户为客户端、服务端和 QA 测试人员。首版目标是提供可重复的本机网络实验入口：选择条件、限定数据包范围、启动/停止、观察统计、保存配置。

## 功能需求（首版）

1. Windows x64 桌面 GUI，中文文案，品牌名称“Motu Net 弱网实验室 · 测试专用”。
2. 场景参数：delay、jitter、loss、blackout、rate limit（KiB/s）、duplicate、reorder、定时停止。
3. 匹配条件：IP、端口、协议、方向、localhost、用户自定义高级 filter。
4. 运行控制：开始/停止、运行状态、管理员权限提示、队列和错误保护。
5. 观测与配置：收发/丢弃/重复/乱序/字节/错误统计；本地 JSON 导入导出；预设场景；本机操作日志。

## 非目标与约束

不支持按进程过滤、直接控制手机、跨平台运行和企业级防篡改审计。TCP 重置（RST）记录为后续能力，首版不得声称支持。程序启动默认为 asInvoker，不自动开启网络拦截，真正开始实验时再请求提权。

## 验收要点

- 未点击开始时不打开 WinDivert 句柄；停止后句柄关闭且队列清空。
- 非法 IP/端口/filter 被阻止并给出中文错误。
- 定时停止在到期后自动结束；统计数值单调且可导出日志。
- 在有管理员权限的 Windows x64 环境完成至少一次真实链路验证；结果由测试记录提供。
