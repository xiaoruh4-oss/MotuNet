# Motu Net 场景库

本目录提供可直接通过 Motu Net「导入场景配置」使用的预设。每个 JSON 文件都是 `schema_version: 1` 配置包，包含完整参数和自动生成的 WinDivert 过滤条件。

## 使用方法

1. 启动 Motu Net（建议以管理员身份运行）。
2. 点击左下角「导入场景配置」，选择本目录中的 JSON 文件。
3. 检查目标范围（默认是整台电脑但排除本机回环），必要时填写服务器 IP/端口。
4. 点击「开始测试」；测试结束后点击「停止并恢复」，或等待场景的自动恢复时间。

## 安全提示

「整台电脑」范围会影响除本机回环外的匹配流量。首次使用建议先导入「01-正常网络」确认链路，再逐步增加限制；测试完成后使用「停止并恢复」确保网络恢复。需要只影响游戏服务器时，请在界面中切换为「指定 IP / 端口」并填写实际目标。

### 断网时序参数

- `start_delay_s`：开始测试后等待多少秒再进入断网阶段，范围 0–86400 秒。
- `blackout_duration_s`：断网阶段持续秒数，范围 0–86400 秒；启用延迟断网时必须至少 1 秒。
- `blackout_loop`：是否循环执行，默认 `false`。设为 `true` 时需启用 `blackout` 且两段时间均至少 1 秒；每轮恢复后重新等待，直到手动停止。
- `duration_s`：普通弱网测试的自动停止时长。断网场景使用 `blackout_duration_s` 控制每次断网时长；循环执行不受普通测试时长限制。
